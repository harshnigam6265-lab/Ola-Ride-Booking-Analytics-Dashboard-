# 🚖 OLA Ride Booking Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing OLA ride-booking data for Bengaluru using **SQL, Microsoft Excel, and Power BI**. The objective is to transform raw booking data into meaningful insights about ride performance, customer behavior, cancellations, revenue, and customer and driver ratings.

The project demonstrates how data analytics can help identify business trends, monitor key performance indicators (KPIs), and support data-driven decision-making.

## 🎯 Business Objectives

- Analyze ride-booking trends over time.
- Understand booking status and ride completion rates.
- Identify the most popular vehicle types based on ride distance.
- Analyze customer and driver cancellation patterns.
- Evaluate revenue by payment method.
- Identify top customers by booking value.
- Compare customer ratings and driver ratings.
- Develop an interactive dashboard to monitor business performance.

## 🛠️ Tools & Technologies

- **Microsoft Excel:** Data cleaning, preprocessing, and preparation.
- **SQL:** Data querying, aggregation, analysis, and view creation.
- **Power BI:** Interactive dashboards, KPI visualization, and business reporting.

## 🗄️ SQL Analysis

SQL was used to answer business questions such as:

1. Retrieve all successful bookings.
2. Calculate average ride distance for each vehicle type.
3. Count rides cancelled by customers.
4. Identify the top 5 customers by number of bookings.
5. Analyze driver cancellations due to personal and vehicle-related issues.
6. Find maximum and minimum driver ratings for Prime Sedan bookings.
7. Retrieve rides paid for using UPI.
8. Calculate average customer ratings by vehicle type.
9. Calculate the total booking value of successful rides.
10. Retrieve incomplete rides along with their reasons.

SQL views were created to organize frequently used queries and simplify analysis.
